# Projects

Automation, analytics, and the occasional tool I built because I wanted to understand how it works.

## Business operations

### [Automating SharePoint Online Migration: Saving $450K Annually](/projects/automating-sharepoint-online-migration-streamlining-and-saving-450k-annually)

Python, SharePoint Online and Microsoft Graph APIs, Azure AD. A batch migration script that moved 20+ TB out of SharePoint Online without a paid SaaS tool, with validation, retries, and permission mapping built in.

### [Zendesk Auto-Recovery Script for Suspended Tickets](/projects/ensuring-business-continuity-zendesk-auto-recovery-script-for-suspended-tickets)

Python, Zendesk API. This script recovers tickets that Zendesk suspends under its 400-emails-per-hour domain limit, which keeps permit and interconnection requests moving.

### [Automating Zendesk Custom Field Updates with Excel](/projects/automating-zendesk-custom-field-updates-with-an-external-excel-sheet)

Python, pandas, Azure Functions, SharePoint. This lets HR maintain Zendesk dropdown fields from a spreadsheet they already own.

### [Optimizing Zendesk License Management](/projects/optimizing-zendesk-license-management-the-inactive-user-downgrade-script)

Python, Zendesk API, Azure Functions. This script downgrades agents who have been inactive for 45+ days across multiple Zendesk tenants before license renewal.
